# 🎮 Java Simulators

A collection of simple **Java console-based simulators** built to practice core programming concepts, logic, and user interaction.

## 🚀 Projects

### 🎲 Dice Simulator

Simulates rolling two dice and displays the results.

### 🏦 ATM Simulator

A console-based ATM system with:

* Check Balance
* Deposit Money
* Withdraw Money
* Exit

### ⏱️ Countdown Timer

A console-based timer that counts down from the number of seconds entered by the user.

* Enter countdown duration
* Displays remaining time
* Shows **TIME'S UP** when the countdown finishes

## 🛠️ Tech Stack

* Java
* Core Java & OOP Concepts
* Scanner for User Input
* Switch-Case
* Loops
* Thread.sleep()

## ▶️ Run

### Dice Simulator

```bash
javac DiceSimulator.java
java DiceSimulator
```

### ATM Simulator

```bash
javac ATM.java
java ATM
```

### Countdown Timer

```bash
javac CountdownTimer.java
java CountdownTimer
```
