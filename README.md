# 🎮 Java Simulators

A collection of simple **Java console-based simulators** built to practice core programming concepts, logic, and user interaction.

## 🚀 Projects

### 🎲 Dice Simulator

Simulates rolling two dice and displays the results.

### 🏦 ATM Simulator

A console-based ATM system with:

* Check Balance
* Deposit Money
* Withdraw Money
* Exit

### 🚦 Traffic Signal Simulator

Simulates traffic signal behavior based on the selected light:

* 🔴 Red → Stop
* 🟡 Yellow → Get Ready
* 🟢 Green → Go

## 🛠️ Tech Stack

* Java
* Core Java & OOP Concepts
* Scanner for User Input
* Switch-Case

## ▶️ Run

### Dice Simulator

```bash
javac DiceSimulator.java
java DiceSimulator
```

### ATM Simulator

```bash
javac ATM.java
java ATM
```

### Traffic Signal Simulator

```bash
javac TrafficSignalSimulator.java
java TrafficSignalSimulator
```
